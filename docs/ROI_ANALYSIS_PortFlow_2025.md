## 5. Financial Metrics

### 5.1 Return on Investment (ROI)

**Formula:** ROI = (Total Benefits - Total Costs) / Total Costs × 100%

**Calculation:**
```
Total 5-Year Benefits = RM 945,810 × 5 = RM 4,729,050
Total 5-Year Costs = RM 234,149 + (RM 14,450 + RM 50,635 × 4) = RM 451,089
Net Benefit = RM 4,729,050 - RM 451,089 = RM 4,277,961

ROI = (RM 4,277,961 / RM 451,089) × 100% = 948%
```

**Conservative ROI (30% risk adjustment):**
```
Conservative Benefits = RM 4,729,050 × 70% = RM 3,310,335
Conservative Net Benefit = RM 3,310,335 - RM 451,089 = RM 2,859,246
Conservative ROI = (RM 2,859,246 / RM 451,089) × 100% = 634%
```

**Result:** **634% ROI over 5 years (conservative)**

---

### 5.2 Payback Period

**Calculation:**
```
Year 0: -RM 234,149
Year 1: -RM 234,149 + RM 647,617 = +RM 413,468
```

**Payback Period:** **Less than 12 months** (conservative estimate: 18-24 months accounting for ramp-up)

---

### 5.3 Net Present Value (NPV)

**Assumptions:**
- Discount rate: 10% (cost of capital)
- 5-year analysis period

**Calculation:**
```
NPV = Σ [Cash Flow / (1 + r)^t] - Initial Investment

Year 1: RM 647,617 / 1.10 = RM 588,743
Year 2: RM 611,432 / 1.21 = RM 505,316
Year 3: RM 611,432 / 1.331 = RM 459,378
Year 4: RM 611,432 / 1.4641 = RM 417,616
Year 5: RM 611,432 / 1.61051 = RM 379,651

NPV = (RM 588,743 + RM 505,316 + RM 459,378 + RM 417,616 + RM 379,651) - RM 234,149
NPV = RM 2,350,704 - RM 234,149 = RM 2,116,555
```

**Result:** **NPV = RM 2,116,555** (highly positive, project is financially viable)
